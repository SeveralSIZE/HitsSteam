# HitsSteam / 19 команда

Сервис пополнения баланса Steam. Пользователь регистрируется, привязывает карту и пополняет баланс.

## Запуск

```bash
docker-compose up --build
```

Порты:
- `8080` — бэкенд (Spring Boot)
- `80` — клиент (Nginx)

## Стек

- Java 17, Spring Boot 4, PostgreSQL 15
- Spring Security + JWT (Auth0 java-jwt)
- Flyway миграции
- Docker Compose

## Бизнес-логика

1. Пользователь регистрируется и логинится
2. Привязывает банковскую карту
3. Выбирает карту и пополняет баланс Steam

## Флаг

Флаг хранится в поле `card_number` таблицы `saved_cards` в зашифрованном виде.

**PUT** — чекер регистрирует пользователя, логинится, добавляет карту с `cardNumber = FLAG`.

**GET** — чекер логинится под тем же пользователем, вызывает `GET /cards`, сервис возвращает номер карты = флаг.

## Чекер

Для работы эксплойтов и чекера нужно в папку exploits закинуть файл rockyou.txt, для гита файл слишком большой, скину его в гк

```bash
pip3 install -r requirements.txt --break-system-packages

python3 checker.py 127.0.0.1 8080 check
python3 checker.py 127.0.0.1 8080 put
python3 checker.py 127.0.0.1 8080 get
python3 checker.py 127.0.0.1 8080 get_flags
```

## Уязвимости

### Открытый swagger

Swagger доступен всем по адресу `http://localhost:8080/swagger-ui/index.html`, можно посмотреть все эндпоинты, их аргументы и т.д.

### Слабое хеширование чувствительных данных

Все данные - пароли, карточки - хешируются слабым md5 хешем без соли

### SQL-инъекция — GET /users/search?q=

Запрос строится конкатенацией строк, параметр `q` никак не экранируется, вставляется в запрос напрямую.

```
GET /users/search?q=' UNION SELECT id, username, password_hash FROM users--
```

Возвращает логины и хеши паролей всех пользователей. Из-за того что хеши это md5 без соли, можно через радужную таблицу узнать пароль, зайти под пользователем нужным и посмотреть флаг напрямую

### Слабый JWT секрет + подмена роли — POST /auth/login

Секрет JWT хранится в `application.yml` открытым текстом и брутится по rockyou.txt. Роль пользователя читается напрямую из токена без проверки в БД, что позволяет подменить `role: USER` на `role: ADMIN` и переподписать токен.

После получения секрета — подделка токена с ролью ADMIN, затем `GET /admin/users` для списка пользователей и `GET /admin/users/{id}/cards` для получения карт.

### OS Command Injection — GET /stats?date=

Параметр `date` передаётся напрямую в системную команду без санитизации.

```
date = "x || cat /app/logs/application.log #"
```

Можно получить логи приложения, в логах содержатся номера карт в открытом виде — флаги всех пользователей.
